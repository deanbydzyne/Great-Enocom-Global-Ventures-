This is the Codex-ready working folder for the existing GREAT ENOCOM GLOBAL VENTURES storefront.

## Existing project — continue, do not rebuild
The index.html file is the approved Step 2 baseline. Preserve the existing storefront, customer journey, official logo, product data and brand identity. Make only small, reversible, owner-approved changes.

## Mobile-first workflow
The owner works strictly from an Android phone. Keep project instructions, catalogue maintenance and GitHub/Codex workflows practical on mobile. Do not require a laptop, command line or Termux.

## Current architecture
- Single-page static HTML with inline CSS and JavaScript.
- Product catalogue currently embedded in the HTML.
- Hash-based navigation.
- Browser localStorage order list under key gegv-cart.
- Owner-supplied product image URLs and existing fallback behaviour.
- WhatsApp enquiry and copy-summary workflow.
- No backend, package manager or build step.
